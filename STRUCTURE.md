# Структура репозитория

Карта каталогов и файлов с описанием — для тех, кто впервые открывает репозиторий. Общий обзор и
быстрый старт — в [README.md](README.md), технические правила — в [AGENTS.md](AGENTS.md).

## Корень

| Файл                | Описание                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------------- |
| `README.md`         | Обзор репозитория для людей: что это, таблица скиллов, быстрый старт, плагины.               |
| `AGENTS.md`         | Технические правила для агента (Claude/Codex/Cursor): структура, конвенции скиллов, границы. |
| `CLAUDE.md`         | Импортирует общие инструкции из `AGENTS.md` (`@AGENTS.md`).                                  |
| `SOUL.md`           | Тон и принципы работы отдела: зачем скиллы существуют, как они не должны себя вести.         |
| `SECURITY.md`       | Политика безопасности: как сообщить об уязвимости, работа с API-ключами, scope.              |
| `DESIGN.md`         | Дизайн-система Figma-плагина: CSS-переменные, компоненты, чеклист перед PR с UI.             |
| `STRUCTURE.md`      | Карта исходников, конфигурации и результатов сборки.                                         |
| `package.json`      | Единственный npm-манифест репозитория; скрипт `build:k-editor` собирает базу знаний плагина. |
| `.prettierrc`       | Настройки Prettier: отступы, кавычки, переносы строк.                                        |
| `.prettierignore`   | Исключения форматирования: зависимости, lock-файл, симлинки и генерируемый пакет.            |
| `package-lock.json` | Закреплённое дерево зависимостей инструментов разработки.                                    |
| `.gitignore`        | Стандартные исключения (macOS, `node_modules/`, `.env*`, IDE-файлы).                         |

## `figma-plugins/k-editor/` — Figma-плагин «К редактор»

Содержит только код плагина; данные и сборка вынесены наружу (`references/`, `tools/`).

| Файл            | Описание                                                                                                  |
| --------------- | --------------------------------------------------------------------------------------------------------- |
| `manifest.json` | Манифест Figma-плагина: точки входа, `networkAccess.allowedDomains`.                                      |
| `code.js`       | Backend-логика плагина (доступ к макету, применение правок к текстовому слою).                            |
| `ui.html`       | UI плагина; между `<!-- BUNDLED:START/END -->` вшита база знаний (генерируется, не редактировать руками). |

## `plugins/inside-k/` — пакет скиллов для Codex

- `.codex-plugin/plugin.json` — метаданные и версия пакета.
- `skills/` — все скиллы, их справочники и примеры; результат сборки из `.agents/skills/`.
- `references/` — общая редполитика и реестр; результат сборки из корневой `references/`.

Файлы пакета сохраняются в Git. Копии генерируются командой `npm run update:plugin`,
вручную редактируются только исходники. Ссылки на общую базу адаптируются при сборке.
Каталог `.agents/plugins/marketplace.json` подключает пакет к Codex.

## `tools/` — сборка

| Файл                 | Описание                                                                                                                                                             |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `update-k-editor.js` | Собирает Figma-плагин и пакет Codex из `.agents/skills/` и `references/`, проверяет манифест, код и ссылки. Запуск: `npm run update:plugin`; `--check` — без записи. |

## `.claude/` — конфигурация Claude Code

Технические инструкции для агентов находятся в корневом `AGENTS.md`.

| Файл                                    | Описание                                                                                                                                                  |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.claude/skills`                        | Симлинк на `.agents/skills` — та же папка под путём, который ждёт Claude Code.                                                                            |
| `.claude/settings.json`                 | Allowlist команд и подключение хука-напоминания о сборке скиллов и справочников.                                                                          |
| `.claude/hooks/remind-content-build.js` | Хук Claude Code: напоминает о сборке при изменении любого скилла или справочника, включая пути через симлинки; принимает абсолютные и относительные пути. |

## `.cursor/` — подключение Cursor

`.cursor/skills` — симлинк на `../.agents/skills`, как и `.claude/skills`.
Все шесть скиллов и их локальные справочники доступны через общий каталог исходников.
