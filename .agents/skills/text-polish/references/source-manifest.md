# Source manifest

## Назначение

Этот файл фиксирует канонические источники, по которым сформирована встроенная офлайн-база скилла `design-text-polish`, и правила её обновления. Критичные редакторские правила продублированы непосредственно в `SKILL.md`, чтобы скилл оставался автономным в средах, где нельзя загружать дополнительную информацию из сетевых источников.

## Последняя сверка

Дата: 2026-09-11.

Канонические страницы:

- https://in.kontur.ru/text — корпоративная редполитика. Страница может требовать внутренний доступ. При последней сборке её полный текст не удалось получить из внешнего окружения, поэтому офлайн-база содержит основные принципы редполитики, подтверждённые публичными Контур.Гайдами, а эта страница остаётся источником для последующей сверки при наличии доступа.
- https://guides.kontur.ru/principles/text/styleguide/ — текст в интерфейсе.

- https://guides.kontur.ru/principles/text/layouts-data/ — данные в макетах и прототипах.
- https://guides.kontur.ru/principles/text/glossary/ — принципы выбора слов и пользовательская терминология.

Дополнительная публичная проверка основных принципов редполитики:

- https://guides.kontur.ru/principles/guides/ — информационный стиль, простой синтаксис, обычные глаголы, подлежащее вместо пассивного залога, отказ от канцеляризмов и усилителей оценки.

## Как проверять обновления

1. Сначала использовать встроенные правила `SKILL.md` как полную рабочую базу.
2. При доступном вебе открыть канонические страницы и искать изменения правил, а не просто изменения оформления или примеров.
3. Применять новое правило в текущей задаче только если изменение однозначно и относится к редактуре текста.
4. Не считать перестановку блоков, новый пример или косметическую правку новым правилом.
5. Не переписывать файлы скилла автоматически.
6. Если требуется обновить сам пакет, сделать новую явную сборку скилла и обновить дату в этом манифесте.
