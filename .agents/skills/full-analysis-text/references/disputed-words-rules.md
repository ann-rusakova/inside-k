# Спорные слова — правила Редполитики

## Устоявшиеся заимствования пишем по-русски

Популярные иностранные слова и аббревиатуры, которые уже приняты словарями и используются большинством людей, пишем по-русски, с маленькой буквы (это не имена собственные, а названия широкого круга явлений).

- SMS → смс
- web-камера → веб-камера, камера на ноутбуке
- Online → онлайн, онлайн-
- Deadline → дедлайн
- call-центр → колл-центр
- Исключение: email (а не e-mail или имейл)

Грейды можно называть и по-английски, и по-русски. На русском используем: **джун, мидл, сеньор** (не «джуниор»/junior, не «миддл»/middle, не «синьор»/«сениор»/senior).

## Неосвоенное — по-английски

Иностранные аббревиатуры, слова и словосочетания, которые ещё не вошли в язык и на практике пишутся по-разному, оставляем на английском — это иногда помогает избежать путаницы в толковании.

- ИТ, IT-технологии → **IT**
- АПИ → **API**
- Бигдата, Большие данные → **Big Data**

Для слов, не попавших в таблицу: если англоязычное написание распространено больше или наравне с русскоязычным, проект выбирает написание сам (проверить популярность можно в Вордстате) — но важно быть последовательным и писать одинаково везде.

## Не используем англицизмы

Если у заимствования есть лаконичный русский аналог — пишем по-русски. Необоснованные заимствования засоряют речь и делают её малопонятной.

- пролонгирование → продление
- митинг → встреча
- ресерч, рисерч → исследование
- аттачить → прикрепить к письму
- паблик релейшнз → связи с общественностью, PR
- фидбэк → обратная связь, отзывы
- роадмап → дорожная карта, план работы

Внутри Контура профессиональные жаргонизмы (бэклог, юзер, фронтенд, утилита) исключить из речи нельзя, но с внешней аудиторией нужно общаться на понятном большинству языке.

## Сложносоставные слова пишем слитно

Слова, образованные по модели «существительное + подчинённое слово» (физическое лицо → физлицо, государственная поддержка → господдержка), пишем слитно — без точек и дефисов.

- юр. лица → юрлица
- корп. сегмент → корпсегмент
- масс. сегмент → массегмент
- штрих. код → штрихкод
- промо-акция → промоакция
- демо-версия → демоверсия
- мед. учреждение → медучреждение
- доп.соглашение → допсоглашение

Если второй корень начинается с гласной и слитное написание звучит неблагозвучно, слово можно развернуть в словосочетание: персучёт → персонифицированный учёт, туриндустрия → туристическая индустрия, допусловия → дополнительные условия.

## Сложносоставные из двух или трёх иностранных слов — через дефис

Словари пока не утвердили орфографическую норму для таких слов, поэтому выбираем дефисное написание.

- конфколл → конф-колл
- роллап → ролл-ап
- сервиспак → сервис-пак
- коллцентр → колл-центр

Трёхкорневые сложносоставные слова неудобно читать слитно. Если одно из слов можно считать отдельным термином, цепляем его к следующему через дефис (по аналогии с «бизнес-задача», «онлайн-встреча»):

- финтехстартап → финтех-стартап
- физтехкласс → физтех-класс
- хайтекпроект → хайтек-проект
- ноунеймпродукт → ноунейм-продукт

## Сервис уже подразумевает онлайн

Говорим просто «сервис», а не «веб-сервис» или «онлайн-сервис» (эти варианты допустимы, только если важно подчеркнуть, что система работает из браузера). Не путаем сервисы и программы:

- **Сервисы** — работают из браузера: Диадок, Экстерн, Фокус, Закупки, сервис Бухгалтерия и подобные.
- **Программы** (десктопные продукты) — устанавливаются на компьютер и могут работать без интернета: Персонал, Зарплата, Бухгалтерия Бюджет и Бухгалтерия Актив и их модули.

## Не усложняем общепринятые сокращения

Есть сокращения, употребление которых расходится с правилами русского языка — ФИО и «мск» (для часового пояса).

- ФИО пишем без точек между буквами — так легче читать, и это написание встречается чаще: «Укажите Ф.И.О. сотрудника» → «Укажите ФИО сотрудника».
- Часовой пояс обозначаем строчными буквами — по аналогии с «млрд», «млн»: «Вебинар пройдёт в 12:00 (МСК)» → «Вебинар пройдёт в 12:00 мск»; «Вебинар пройдёт в 12:00 по МСК времени» → «Вебинар пройдёт в 12:00 по мск времени».
