# Дизайн-система Figma-плагинов

Справочник по интерфейсу `figma-plugins/simple-editor/ui.html`. Это единственный файл в репозитории
со своим визуальным дизайном: скиллы и `references/` — текст.

## Характер интерфейса

Плагин открывается поверх макета пользователя и повторяет системный UI Figma: нейтральная светлая
палитра, компактные контролы, минимум декора. Своего бренда у интерфейса нет, главное на экране —
результат проверки текста.

- Тема одна, светлая. Переключатель тем не нужен, пока Figma не потребует адаптации под тёмный UI.
- При `prefers-reduced-motion` медиа-запрос обнуляет `--dur-fast`, `--dur-base` и
  `--fragment-highlight-dur`.
- Экраны идут шагами одного потока, от выбора действия через загрузку к результату. Многоуровневой навигации
  нет, `nav-row` и `nav-deep` дают только «назад» и «закрыть».

## Где что лежит

Весь интерфейс — в `figma-plugins/simple-editor/ui.html`:

| Что                                 | Где                                                                        |
| ----------------------------------- | -------------------------------------------------------------------------- |
| CSS-переменные: цвета, длительности | `:root` в начале `<style>`                                                 |
| Иконки                              | объект `ICONS` со строками инлайн SVG                                      |
| Экраны и разметка                   | функции `*View()`: `introView`, `settingsView`, `analysisResultView` и др. |
| Рендер и обработчики                | `render()`, `bindEvents()`, `morph*`                                       |

Разметка собирается шаблонными строками, DOM обновляется вручную функциями `morph*`. Фреймворка и
сборки CSS нет, все стили — в одном блоке `<style>`.

## Цвета

Переменные в `:root` заданы значениями hex и rgba, семантических токенов нет. Писать в компоненте
`background: var(--brand-blue)` в этом файле нормально.

| Группа             | Переменные                                                                                         | Назначение                                                  |
| ------------------ | -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| Бренд              | `--brand-blue`, `--brand-navy`, `--brand-green`, `--brand-orange`, `--brand-red`, `--brand-purple` | Акценты, иконки, кнопки                                     |
| Текст              | `--text`, `--muted`, `--caption`, `--header`                                                       | Основной и вторичный текст, подписи                         |
| Поверхности        | `--bg`, `--surface`, `--card`, `--card-hover`, `--card-active`                                     | Фон страницы, карточки                                      |
| Границы            | `--border`, `--border-soft`                                                                        | Разделители, обводки полей                                  |
| Оценка текста      | `--score-red-*`, `--score-yellow-*`, `--score-green-*` (bg, border, tag)                           | Диапазоны индекса качества 0–10                             |
| Кнопка «Сохранить» | `--dark-btn`, `--dark-btn-hover`, `--dark-btn-active`, `--dark-btn-text`                           | Единственная тёмная кнопка, основное действие               |
| Оверлеи            | `--overlay-04` … `--overlay-32`                                                                    | Полупрозрачный чёрный для hover и active поверх любого фона |

Для hover и active сначала подберите один из 11 существующих `--overlay-*`. Новую rgba-переменную под
отдельный компонент не заводите.

## Типографика

Шрифт один на весь интерфейс: `--font-family: "Lab Grotesque", "Lab Grotesque K", Inter,
-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`. Это бренд-шрифт Контура с системными
запасными вариантами. Моноширинного шрифта нет: плагин показывает только обычный текст, без кода и
путей.

## Компоненты

Перед новой разметкой поищите готовый класс:

| Класс                                     | Когда использовать                                           |
| ----------------------------------------- | ------------------------------------------------------------ |
| `.btn-save`                               | Основное действие, тёмная кнопка                             |
| `.btn-check`                              | Второстепенное действие рядом с основным, обводка без фона   |
| `.icon-btn`                               | Кнопка-иконка без текста: навигация, помощь                  |
| `.action-card`                            | Крупная карточка выбора режима на стартовом экране           |
| `.action-btn`                             | Кнопка режима правки: «Переформулировать», «Сократить» и др. |
| `.more-btn`                               | Вторичная кнопка во всю ширину внизу экрана                  |
| `.toggle-row`                             | Строка переключателя в настройках                            |
| `.field` / `.select-input` / `.key-input` | Поле формы с подписью                                        |
| `.mode-loader-overlay`                    | Индикатор загрузки поверх результата, не на весь экран       |

Похожий паттерн может уже существовать под другим именем. Проверьте командой
`grep -n "class=\"" ui.html`.

## Иконки

Иконки — только инлайн SVG в объекте `ICONS`. Шрифты-иконки и спрайты через `<img>` не подключайте.
Новую иконку добавьте строкой SVG с тем же `viewBox` и толщиной линий, что у остальных.

## Движение

- `transition` для интерактивных элементов задан одним селектором в начале `<style>`
  (`button, .icon-btn, .action-card, …`). В отдельных классах его не повторяйте.
- Длительности берите из `--dur-fast` и `--dur-base`, числа вроде `150ms` не пишите.

## Чеклист перед PR с изменением UI

- [ ] Цвет взят из существующей CSS-переменной, нового hex в разметке нет
- [ ] Для новой кнопки проверены `.btn-save`, `.btn-check` и `.more-btn`
- [ ] Иконка добавлена в `ICONS`, а не отдельным файлом
- [ ] Анимация использует `--dur-fast` или `--dur-base` и отключается при `prefers-reduced-motion`
- [ ] Плагин проверен в Figma через `Import plugin from manifest...`, а не только в браузерном mock-режиме
- [ ] После правки базы знаний запущен `npm run update:simple-editor`
