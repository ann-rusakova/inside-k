# Дизайн-система Figma-плагинов

Справочник по UI `figma-plugins/k-editor/ui.html` — единственному месту в репозитории с
собственным визуальным дизайном (скиллы и `references/` — это текст, не интерфейс).

## Характер интерфейса

Плагин встраивается в интерфейс Figma поверх макета пользователя, поэтому визуально
подстраивается под системный UI Figma, а не строит собственный бренд: нейтральная
светлая палитра, компактные контролы, минимум декора. Внимание — на содержании
(результат проверки текста), а не на оформлении карточек.

- Фиксированная светлая тема — переключателя light/dark нет и не планируется, пока
  сама Figma не потребует адаптации под тёмный UI.
- `prefers-reduced-motion` уважается: все длительности анимаций (`--dur-fast`,
  `--dur-base`, `--fragment-highlight-dur`) обнуляются в соответствующем медиа-запросе.
- Экраны — модальные шаги одного потока (выбор действия → загрузка → результат), а не
  многоуровневая навигация: `nav-row`/`nav-deep` дают только «назад»/«закрыть».

## Источник правды

Всё в одном файле — `figma-plugins/k-editor/ui.html`:

| Что                                  | Где                                                                          |
| ------------------------------------ | ---------------------------------------------------------------------------- |
| CSS-переменные (цвета, длительности) | `:root` в начале `<style>`                                                   |
| Иконки                               | объект `ICONS` (инлайн SVG-строки)                                           |
| Экраны/разметка                      | функции `*View()` (`introView`, `settingsView`, `analysisResultView` и т.д.) |
| Рендер и обработчики                 | `render()`, `bindEvents()`, `morph*`                                         |

Верстка — шаблонные строки (template literals) с ручным diff/patch DOM через `morph*`,
без фреймворка и без сборки CSS — весь стиль живёт в одном `<style>` блоке.

## Цвета

Переменные заданы как raw hex/rgba в `:root`, не как семантические токены — прямое
использование `background: var(--brand-blue)` в компонентах нормально для этого файла.

| Группа             | Переменные                                                                                         | Назначение                                                                           |
| ------------------ | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Бренд              | `--brand-blue`, `--brand-navy`, `--brand-green`, `--brand-orange`, `--brand-red`, `--brand-purple` | Акценты, иконки, кнопки                                                              |
| Текст              | `--text`, `--muted`, `--caption`, `--header`                                                       | Основной/вторичный/подписи текст                                                     |
| Поверхности        | `--bg`, `--surface`, `--card`, `--card-hover`, `--card-active`                                     | Фон страницы, карточки                                                               |
| Границы            | `--border`, `--border-soft`                                                                        | Разделители, обводки полей                                                           |
| Оценка текста      | `--score-red-*`, `--score-yellow-*`, `--score-green-*` (bg/border/tag)                             | Индекс качества 0–10: красный/жёлтый/зелёный диапазоны                               |
| Кнопка «Сохранить» | `--dark-btn`, `--dark-btn-hover`, `--dark-btn-active`, `--dark-btn-text`                           | Единственная тёмная кнопка в интерфейсе — основное действие                          |
| Оверлеи            | `--overlay-04` … `--overlay-32`                                                                    | Прозрачный чёрный разной интенсивности для hover/active состояний поверх любого фона |

**Не заводите новую rgba-переменную под конкретный компонент**, если подходит
существующий `--overlay-*` — их 10 штук с шагом прозрачности специально для этого.

## Типографика

Один шрифт на весь интерфейс: `--font-family: "Lab Grotesque", "Lab Grotesque K",
Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` — бренд-шрифт Контура
с системным фолбэком. Отдельного моно-шрифта для кода/значений нет — плагин не
показывает код или пути, только естественный текст.

## Компоненты

Переиспользуйте существующие классы вместо новой разметки — почти для каждого паттерна
уже есть готовый:

| Класс                                     | Когда использовать                                                 |
| ----------------------------------------- | ------------------------------------------------------------------ |
| `.btn-save`                               | Основное действие (тёмная кнопка)                                  |
| `.btn-check`                              | Второстепенное действие рядом с основным (обводка, прозрачный фон) |
| `.icon-btn`                               | Кнопка-иконка без текста (навигация, помощь)                       |
| `.action-card`                            | Крупная карточка выбора режима на стартовом экране                 |
| `.action-btn`                             | Кнопка режима правки (Переформулировать/Сократить/…)               |
| `.more-btn`                               | Полноширинная вторичная кнопка снизу экрана                        |
| `.toggle-row`                             | Строка переключателя в настройках                                  |
| `.field` / `.select-input` / `.key-input` | Поле формы с подписью                                              |
| `.mode-loader-overlay`                    | Оверлей загрузки поверх результата (не полноэкранный лоадер)       |

Если нужен новый визуальный паттерн — сначала проверьте `grep -n "class=\"" ui.html`,
велика вероятность, что похожий уже есть под другим именем.

## Иконки

Только инлайн SVG из объекта `ICONS` — не подключайте внешние иконочные библиотеки
(шрифт-иконки, `<img>` со спрайтами). Новую иконку добавляйте туда же строкой SVG,
единообразно с существующими (viewBox, толщина линий).

## Движение

- `transition` на интерактивных элементах задаётся централизованно одним селектором в
  начале `<style>` (`button, .icon-btn, .action-card, …`), не на каждом классе отдельно.
- Длительности — только через `--dur-fast`/`--dur-base`, не хардкодить `150ms` напрямую.

## Чеклист перед PR с изменением UI

- [ ] Цвета — через существующую CSS-переменную, не новый hex в разметке
- [ ] Новая кнопка — проверил, нет ли уже подходящего класса (`.btn-save`/`.btn-check`/`.more-btn`)
- [ ] Иконка — добавлена в `ICONS`, не как внешний файл
- [ ] Анимация — через `--dur-fast`/`--dur-base`, работает и с `prefers-reduced-motion`
- [ ] Проверено в самой Figma (`Import plugin from manifest...`), не только в браузерном mock-режиме
- [ ] После правки текста базы знаний — не забыт `npm run build:k-editor`
