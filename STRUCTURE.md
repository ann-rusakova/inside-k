# Структура репозитория

Полный список файлов с описанием — для тех, кто впервые открывает репозиторий. Общий обзор и
быстрый старт — в [README.md](README.md), технические правила — в [AGENTS.md](AGENTS.md).

## Корень

| Файл                | Описание                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------- |
| `README.md`         | Обзор репозитория для людей: что это, таблица скиллов, быстрый старт, плагины.                    |
| `AGENTS.md`         | Технические правила для агента (Claude/Codex/Cursor): структура, конвенции скиллов, границы.      |
| `CLAUDE.md`         | Импортирует `AGENTS.md` (`@AGENTS.md`) + Claude-специфичное примечание про симлинк скиллов.       |
| `SOUL.md`           | Тон и принципы работы отдела: зачем скиллы существуют, как они не должны себя вести.              |
| `SECURITY.md`       | Политика безопасности: как сообщить об уязвимости, работа с API-ключами, scope.                   |
| `DESIGN.md`         | Дизайн-система Figma-плагина: CSS-переменные, компоненты, чеклист перед PR с UI.                  |
| `STRUCTURE.md`      | Этот файл — построчное описание каждого файла репозитория.                                        |
| `package.json`      | Единственный npm-манифест репозитория; скрипт `build:simple-editor` собирает базу знаний плагина. |
| `.prettierrc`       | Настройки Prettier: отступы, кавычки, переносы строк.                                             |
| `.prettierignore`   | Исключения форматирования: зависимости, lock-файл и симлинк скиллов.                              |
| `package-lock.json` | Закреплённое дерево зависимостей инструментов разработки.                                         |
| `.gitignore`        | Стандартные исключения (macOS, `node_modules/`, `.env*`, IDE-файлы).                              |

## `.agents/skills/` — источник правды для скиллов

`.claude/skills` — симлинк на эту папку, редактировать нужно только здесь.

| `SKILL.md`                            | Проектирует структурированный гайд для UX-интервью по методологии Крюгера и Квале. |

| `reference/guide-structure.md`        | Шаблоны и примеры формулировок для каждого блока гайда.                            |
| `reference/krueger-principles.md`     | Обоснование методологии по Крюгеру и Кейси (Focus Groups, 5th ed.).                |
| `reference/kvale-question-design.md`  | Проектирование вопросов по Стейнару Квале («Исследовательское интервью»).          |
| `reference/question-rules.md`         | Правила формулировки вопросов для UX-интервью, адаптация Крюгера.                  |

## `references/` — общая база знаний (общий источник)

Единственный источник правил; на него ссылаются скиллы `only-editor`/`full-analysis-text` и
собирает Figma-плагин через `tools/update-content-simple-editor.js`.

| Файл           | Описание                                                                                           |
| -------------- | -------------------------------------------------------------------------------------------------- |
| `sources.json` | Реестр источников: заголовок, URL, файл, флаг `editorFocus` — единственный список, не дублируется. |

## `plugins/simple-editor/` — Figma-плагин «Просто редактор»

Содержит только код плагина; данные и сборка вынесены наружу (`references/`, `tools/`).

| Файл            | Описание                                                                                                  |
| --------------- | --------------------------------------------------------------------------------------------------------- |
| `manifest.json` | Манифест Figma-плагина: точки входа, `networkAccess.allowedDomains`.                                      |
| `code.js`       | Backend-логика плагина (доступ к макету, применение правок к текстовому слою).                            |
| `ui.html`       | UI плагина; между `<!-- BUNDLED:START/END -->` вшита база знаний (генерируется, не редактировать руками). |

## `tools/` — сборка

| Файл                              | Описание                                                                                                                                                         |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `update-content-simple-editor.js` | Читает `references/editorial-policy/` и `references/sources.json`, вшивает базу знаний в `plugins/simple-editor/ui.html`. Запуск: `npm run build:simple-editor`. |

## `.claude/` — конфигурация Claude Code

Cursor и Codex отдельной конфигурации не требуют — оба читают `AGENTS.md` нативно.

| Файл                                    | Описание                                                                                                                                                 |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.claude/skills`                        | Симлинк на `.agents/skills` — та же папка под путём, который ждёт Claude Code.                                                                           |
| `.claude/settings.json`                 | Allowlist безопасных команд + хук-напоминание про `npm run build:simple-editor` при правке `references/editorial-policy/` или `references/sources.json`. |
| `.claude/hooks/remind-content-build.js` | Хук Claude Code: напоминает о сборке при изменении редполитики или реестра; принимает абсолютные и относительные пути.                                   |
